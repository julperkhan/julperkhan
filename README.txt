MOHAMED JULPERKHAN — PORTFOLIO

GET STARTED
Unzip the entire folder, then open index.html in your browser. No framework, install, or build is needed. Upload the folder contents to any static website host.

WHATSAPP SETUP
The supplied +91 is only a country code. Your complete WhatsApp phone number is still needed. In config.js, put your full number including country code inside the empty quotes, digits only (no +, spaces, or dashes).
Without a full number, the form offers message copying and your contact email.
With a number, the form opens WhatsApp with a prepared message. The visitor must review the message and press Send in WhatsApp; the website does not automatically send it.

FILES
index.html: portfolio content
styles.css: colors, layout, animations, mobile styles
script.js: navigation, project filters, previews, testimonials and contact
contact-utils.js: form validation and safe WhatsApp URL generation
config.js: WhatsApp recipient
assets/: your original portraits and three generated project concept images

CONTENT NOTES
Original email, skills, work history, projects, and testimonial copy were retained. Placeholder social links were removed because no real profile URLs were supplied. The three new project images are illustrative generated concept visuals, not actual screenshots of your work. Original testimonial attributions are generic and should be replaced with verified testimonials before professional use.

Fonts use Google Fonts when online and fall back to local system fonts offline. Images and all site code are included locally. The site works without JavaScript for reading and navigation, while the interactive features need JavaScript. Reduced-motion preferences are respected.
